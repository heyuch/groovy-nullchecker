# Corpus manifest
#
# One block per fixture, introduced by its path relative to corpus/:
#
#   positive/nonnull_return.groovy
#   rule=R01
#   strict=any
#   expect=some
#
# Keys
#   rule     rule id this fixture exercises; must exist in CorpusRules
#   strict   any | only | never
#              any  : same expectation with and without strict mode
#              only : must fire with strict, must be silent without it
#              never: must stay silent in both modes
#   expect   none | some | <n>
#   note     free text
#
# The gate fails when a fixture on disk is undeclared, when a declaration has no file,
# when a rule id is unknown, or when a rule is never exercised by any fixture. Drift
# and uncovered rules must be impossible rather than merely discouraged.
#
# `expect=some` means "at least one". Repeated rule ids are deliberate: several
# fixtures exercise different shapes of the same rule.
